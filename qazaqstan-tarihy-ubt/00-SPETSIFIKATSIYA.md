Мемлекеттің негізін салушылар – Жәнібек пен Керей. Қазақ хандығы қалыптасуының алғашқы жылдарындағы ішкі және сыртқы саясаты. Біртұтас қазақ мемлекеті қалыптасуының тарихи маңызы |

|  | 18 | Қазақ хандығының мемлекеттік-әкімшілік құрылымы. Қазақ қоғамының әлеуметтік стратификациясы, экономикасы. Қазақтардың дәстүрлі шаруашылығы: мал шаруашылығы, егіншілік |
|  | 19 | XVIII ғасырдың басындағы Қазақстан: сыртқы және ішкі саяси жағдай. Жоңғар мемлекеті. Қазақ-жоңғар соғыстары. «Ақтабан шұбырынды, алқакөл сұлама» заманы. Қарақұм мен Ордабасыдағы құрылтайлар – қазақ жасағының құрылуы. Аңырақай шайқасы. Отан қорғаушы батырлар. XVIII ғасырдың 30 - 40 жылдарындағы қазақ-жоңғар соғыстары |
|  | 20 | XVIII ғасырдың бірінші жартысындағы Қазақ хандығы. XVIII ғасырдың басына дейінгі қазақ-орыс қатынастары. XVIII ғасырдың басындағы Ресей империясы назарындағы Қазақстан (саяси және экономикалық мақсаттар, әскери-барлау экспедициялары, алғашқы әскери бекіністердің салынуы). Кіші жүз ханы Әбілқайырдың Ресей бодандығын қабылдауы: себептері мен мақсаттары. XVIII ғасырдың 30-50-жылдарындағы Қазақстандағы Ресей империясының саясаты. ХVІІІ ғасырдың 40-жылдарындағы Қазақстандағы ішкі саяси жағдайдың асқынуы |
|  | 21 | Абылай хан тұсындағы Қазақ хандығы: ішкі және сыртқы саясаты |
|  | 22 | Отарлау және ұлт-азаттық күрес. Ресей империясының отаршылдық саясаты: мақсаттары мен әдістері |
|  | 23 | Сырым Датұлы бастаған ұлт-азаттық қозғалыс (себептері, қозғалыстың қозғаушы күші, кезеңдері мен барысы, нәтижелері) |
|  | 24 | 1822-1824 жылдардағы патша реформалары (Кіші және Орта жүздегі хандық биліктің жойылуы) |
|  | 25 | XIX ғасырдың бірінші жартысындағы қазақ халқының ұлт-азаттық қозғалыстары (Жоламан Тіленшіұлы, Саржан Касымов бастаған көтеріліс) |
|  | 26 | 1836-1838 жылдардағы Бөкей ордасындағы қазақтардың көтерілісі (себептері, негізгі кезеңдері мен шайқастары) |
|  | 27 | Кенесары Қасымұлы бастаған ұлт-азаттық қозғалыс (себептері, мақсаттары мен қозғаушы күштері, негізгі кезеңдері). Кенесары Қасымұлы: тұлға және саясаткер |
|  | 28 | Жанхожа Нұрмұхамедұлы және Есет Көтібарұлы бастаған ұлт-азаттық көтеріліс (себептері, көтеріліс барысы). Ресей империясының Қазақстанның оңтүстік аймақтарын қосып алуы. ХVІІІ ғасырдың соңы – XIX ғасырдағы Қазақстандағы ұлт-азаттық қозғалыстардың тарихи маңызы |
|  | 29 | Қазақстан Ресей империясының құрамында. XIX ғасырдың екінші жартысындағы Қазақстандағы патшалық реформалар. 1867-1868 жылдардағы реформалар. Қазақстандағы патшалық Ресейдің аграрлық және қоныстандыру саясаты. |
|  | 30 | 1860-1870 жылдардағы ұлт-азаттық күрес (себептері мен көтеріліс барысы) |
|  | 31 | ХІХ ғасырдың екінші жартысындағы Қазақстанның әлеуметтік-экономикалық дамуы. Капиталистік қатынастардың ене бастауы. Жәрмеңке саудасының дамуы. Сауда қатынастарының дамуы |
|  | 32 | Дәстүрлі қазақ қоғамының трансформациясы. XIX ғасырдың екінші жартысындағы қоғамдық-саяси ойлардың дамуы |
| 4. Қазақстан ХХ | 33 | ХХ ғасырдың басындағы Қазақстан. XX ғасырдың басындағы Қазақстандағы ғасырдың қоғамдық-саяси үдерістер. XX ғасырдың басындағы Қазақстанның экономикалық бірінші дамуы. XX ғасырдың басындағы Қазақстандағы өнеркәсіптің дамуы. Сауданың жартысында дамуы |
|  | 34 | Қазақстандағы 1916 жылғы ұлт-азаттық қозғалыс. 1917 жылғы ақпан буржуазиялық-демократиялық революциясы және оның Қазақстанға әсері |
|  | 35 | «Алаш» қозғалысы және қазақ ұлттық идеясы. Қазақ ұлттық зиялылар қауымы және оның XX ғасырдың басындағы қоғамдық-саяси үдерістерге әсері. Ұлттық баспаның дамуы («Қазақ» газеті, «Айқап» журналы). 1917 жылғы революциялар. «Алаш» партиясының құрылуы. «Алаш-Орда» үкіметі. Қазақ халқының саяси көшбасшылары (Ә. Бөкейхан, А. Байтұрсынов, М. Дулатов, Б. Қаратаев, М. Тынышпаев, М. Шоқай). XX ғасырдың басындағы қазақ зиялыларының ғылыми еңбектері |
|  | 36 | Қазақстандағы Кеңес үкіметінің орнығуы. «Үш Жүз» қазақ социалистік партиясы. Азамат соғысы жылдарындағы (1918-1920 жылдар) Қазақстандағы соғыс қимылдары |
|  | 37 | Кеңес билігі органдарының «Алаш-Орда» үкіметі, Қоқан автономиясымен қарым- қатынасы |
|  | 38 | Қазақ Автономиялы Кеңестік Социалистік Республикасының құрылуы. Қазақ АКСР-ы аумағының қалыптасуы. Қазақ жерлерінің біртұтастығын қалпына келтірудегі қазақ зиялыларының рөлі |
|  | 39 | «Әскери коммунизм саясаты». 1921 жылғы жұт және аштық. Қазақстандағы Жаңа экономикалық саясат |
|  | 40 | Қазақстан тоталитарлық жүйенің нығаюы кезеңінде. Қазақстандағы социалистік индустрияландыру (мәні мен ерекшеліктері). «Кіші Қазан» (мазмұны және жүзеге асырылуы). Бай шаруашылықтарының тәркіленуі. Ауыл шаруашылығындағы күштеп ұжымдастыру саясаты. Қазақстандағы күштеп ұжымдастыру саясатының экономикалық салдары. 1931-1933 жылдардағы аштық - ХХ ғасырдағы қазақстандық қасірет. Қазақстандағы ұжымдастырудың демографиялық салдарлары. Ұжымдастыруды жүзеге асырудың әдістеріне қатысты ұлттық зиялылардың («Бесеудің хаты») қоғамдық-саяси көзқарасы мен қатынасы |
|  | 41 | 1920-1930 жылдардағы Қазақстандағы қоғамдық-саяси процестер. Сталиндік репрессиялар. Қазақстан аумағындағы кеңестік «еңбек түзеу» концентрациялық лагерлері (Степлаг, Карлаг, Алжир) |
|  | 42 | Қазақстан Ұлы Отан соғысы жылдарында. Қазақстандықтардың Ұлы Отан соғысы жылдарындағы ерлігі мен тағдыры. |
| 5. XX ғасырдың | 43 | Қазақстан соғыстан кейінгі жылдарда (1946-1953 жылдар). Соғыстан кейінгі екінші жылдардағы әлеуметтік-экономикалық өзгерістер. Пайдалы қазбаларды өңдеу және жартысы - өнеркәсіптің дамуы. Ауыл шаруашылығының дамуы. Қазақстанның әскери- XXI өнеркәсіптік кешенінің қалыптасуы (Қазақстандағы ядролық полигон). Соғыстан ғасырдың кейінгі жылдардағы қоғамдық-саяси өмірдің ерекшеліктері. «Бекмаханов ісі» басындағы 44 Қазақстан «Жылымық» кезеңінде (1954-1964 жылдар). Қазақстанда «Хрущевтік Қазақстан кезеңдегі» өнеркәсіптің дамуы. Тың және тыңайған жерлерді игеру (тың игерудің экономикалық, экологиялық және демографиялық салдары). Қазақстандағы әскери- өнеркәсіптік кешен («Байқоңыр» ғарыш айлағы). «Жылымық кезеңі». 1954-1965 жылдардағы республикадағы қоғамдық-саяси өмір |
|  | 45 | Қазақстан «Тоқырау» кезеңінде (1965-1985 жылдар). 1965-1985-жылдардағы Қазақстанның әлеуметтік-экономикалық дамуы. Экономиканың шикізаттық бағыты. Урбанизация. 1970-1980 жылдардағы ауыл шаруашылығындағы дағдарыс. 1965-1985 жылдардағы қоғамдық-саяси өмір. 1979 жылғы Целиноградтағы оқиғалар. Қазақ Кеңестік Социалистік Республикасы басшыларының қызметі (Ж. Шаяхметов, Д. Қонаев, Ж. Тәшенов) |
|  | 46 | Қазақстан Қайта құру кезеңінде (1986-1991 жылдар). «Қайта құру» жылдарындағы әлеуметтік-экономикалық өзгерістер: мақсаттары, проблемалары мен қарама- қайшылықтары. Қазақстандағы 1986 жылғы желтоқсан оқиғалары (себептері, барысы мен салдары). «Қазақ КСР-ның мемлекеттік егемегендігі туралы Декларация». Кеңестік саяси жүйенің дағдарысы |
|  | 47 | КСРО-ның ыдырауы. Қазақстандағы қоғамдық-саяси қозғалыстар. Семей ядролық полигонының жабылуы. «Қазақ КСР-ның тілдер туралы Заңының» қабылдануы. Нарықтық экономикаға көшудегі қиыншылықтар. Қазақстанның әлемдік қауымдастыққа кірігуі. Тәуелсіздіктің алғашқы жылдарындағы әлеуметтік-демографиялық үдерістер. 1995 жылғы Конституцияның қабылдануы.
